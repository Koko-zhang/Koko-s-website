0516《外贸三要素与基础认识》

讲师 周超磊 状态 已发布

课程摘要

本课是前程内训系列的入门第一课。用"客户—产品—服务"三角框架切入外贸本质：客户即市场需求、产品即最基本价值、服务即客户的私人订制，三者共同构成业务底盘。再把"询盘—报价—样品—合同—备货—验货—物流—清关—收款"全流程的关键术语（MOQ、Lead Time、AQL、PSI、INCOTERMS 等）串成一条线。

课程目录

  1. 1外贸业务基础三要素（客户 / 产品 / 服务）
  2. 2外贸基础流程（询盘 → 报价 → 样品 → 合同 → 备货 → 验货 → 物流 → 清关 → 收款）
  3. 3外贸基础术语（报价 / 样品 / 合同 / 单据）

关键知识点卡片

CARD 01

外贸业务的三要素：客户、产品、服务

三角框架从任何一角出发都站得住。三角之外还有四根支撑柱：资金与财务、设计与开发、保质保量的后端、多重存在的服务（账期、IKEA/Inditex/Zara Home 供应商模式、GHT 等）。

业务的天花板往往由三角中"最短的那块木板"决定
CARD 02

外贸基础流程：每个环节都有"可调节误差"

询盘 → 报价 → 样品 → 合同 → 备货 → 验货 → 物流 → 清关 → 收款。每个环节都会产生误差，关键不是消除误差，而是在哪个环节、用什么方式去调节。

报价环节的误差没控住，后面所有流程都要买单。
CARD 03

报价的"价从何来"：六个核心术语

术语含义
Unit Price单价
MOQMinimum Order Quantity 最小起订量
Lead Time生产交期
Validity报价有效期
Payment TermsT/T（电汇）/ L/C（信用证）/ D/P（付款交单）
Port of L / D起运港 / 目的港
报价表 = 价格 × 数量 + 时间和风险条款
CARD 04

样品链：9 种样品别再混淆

  • Sample 样品（总称）
  • PPS（Pre-production sample）产前样——大货生产前最后一道确认
  • Production sample 大货样
  • Approval sample 确认样——客户确认后才能生产，最关键
  • Counter sample 对等样 / 回样
  • Reference sample 参考样
  • Color sample / swatch 色样 / 色卡
  • Lab dip 染色小样（面料）
  • Revise sample 修改样
确认你该做的 & 客户要的——样品是流程的核心控制点
CARD 05

合同履行：验货 + 物流 + 单据全解

① 验货方式

  • PSI（Pre-shipment inspection）出货前检验，最常用
  • Random inspection 随机抽检
  • Third-party inspection 第三方验货

② 缺陷分级（AQL 是核心标准）

等级含义处理原则
Critical严重缺陷安全问题，零容忍
Major主要缺陷影响使用
Minor次要缺陷外观小问题

AQL（Acceptance Quality Limit）接受质量限——验货最核心标准，用百分比衡量可接受的缺陷上限。

③ 验货报告常用词

  • Defect / Fault 不良、缺陷；Pass 合格 / Fail 不合格
  • QC 质检员 / Inspector 验货员
  • Inspection report 验货报告 / Quantity checked 抽检数量
  • Acceptance rate 合格率 / Rejection rate 不良率

④ 不合格后的处理动作

  • Rework 返工 / Repair 返修
  • Sorting 挑选 / Scrap 报废
  • Re-inspect 复检
  • Hold shipment 扣货、暂缓出货 / Release shipment 放行出货

⑤ 物流方式 & 清关术语

  • Door to Door 门到门 / Port to Port 港到港
  • Transshipment 转运
  • Customs Clearance 清关 / D/O（Delivery Order）提货单
  • Pick up 提货 / Consignee 收货人 / Consignor 发货人

⑥ 贸易单据（5 件套 + 优惠证）

单据用途
Invoice 商业发票货值、品名、数量
Packing List 装箱单包装、毛重、净重
Contract 合同买卖双方合同
B/L 海运提单海运提货凭证
AWB 空运运单空运提货凭证
CO / FORM E·F·R 原产地证享受关税优惠

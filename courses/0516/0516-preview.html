课程摘要

本课是前程内训系列的入门第一课。用"客户—产品—服务"三角框架切入外贸本质：客户即市场需求、产品即最基本价值、服务即客户的私人订制，三者共同构成业务底盘。再把"询盘—报价—样品—合同—备货—验货—物流—清关—收款"全流程的关键术语（MOQ、Lead Time、AQL、PSI、INCOTERMS 等）串成一条线。

关键知识点卡片（5 张）

CARD 01

外贸业务的三要素：客户、产品、服务

三角框架从任何一角出发都站得住。三角之外还有四根支撑柱：资金与财务、设计与开发、保质保量的后端、多重存在的服务（账期、IKEA/Inditex/Zara Home 供应商模式、GHT 等）。

业务的天花板往往由三角中"最短的那块木板"决定

CARD 02

外贸基础流程：每个环节都有"可调节误差"

询盘 → 报价 → 样品 → 合同 → 备货 → 验货 → 物流 → 清关 → 收款。每个环节都会产生误差，关键不是消除误差，而是在哪个环节、用什么方式去调节。

报价环节的误差没控住，后面所有流程都要买单。

CARD 05

合同履行：验货 + 物流 + 单据全解

① 验货方式

  • PSI（Pre-shipment inspection）出货前检验，最常用
  • Random inspection 随机抽检
  • Third-party inspection 第三方验货

② 缺陷分级（AQL 是核心标准）

AQL（Acceptance Quality Limit）接受质量限——验货最核心标准，用百分比衡量可接受的缺陷上限。

③ 验货报告常用词

  • Defect / Fault 不良、缺陷；Pass 合格 / Fail 不合格
  • QC 质检员 / Inspector 验货员
  • Inspection report 验货报告 / Quantity checked 抽检数量
  • Acceptance rate 合格率 / Rejection rate 不良率

④ 不合格后的处理动作

  • Rework 返工 / Repair 返修
  • Sorting 挑选 / Scrap 报废
  • Re-inspect 复检
  • Hold shipment 扣货、暂缓出货 / Release shipment 放行出货

⑤ 物流方式 & 清关术语

  • Door to Door 门到门 / Port to Port 港到港
  • Transshipment 转运
  • Customs Clearance 清关 / D/O（Delivery Order）提货单
  • Pick up 提货 / Consignee 收货人 / Consignor 发货人
